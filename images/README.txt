Drop your own photos here, e.g. gift-1.jpg, then set the matching `photo`
path in js/gifts.js (e.g. "images/gift-1.jpg"). Resize photos to about
800px wide first — phone originals are large and slow the page.

Background polaroids work the same way: drop files here (e.g. bg-1.jpg)
and list them in `backgroundPhotos` in js/gifts.js. The optional ending
photo also goes here (e.g. ending.jpg).

No photos are included in this repo. This README exists so the folder is
tracked by git — replace or delete it as you like.
